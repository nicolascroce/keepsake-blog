La vie d'une note n'est pas binaire. Entre la capture instantanée dans l'Inbox et le post fini publié sur votre Page, il y a un entre-deux : l'idée qui demande à être relue, retravaillée, mûrie avant d'être montrée. Jusqu'ici, cet entre-deux n'avait pas d'endroit. Une note était soit dans l'Inbox, soit archivée. Le brouillon qui n'est pas tout à fait prêt se confondait avec la recette de cuisine et le code de réservation.

<mark>Vos notes peuvent désormais suivre un cheminement éditorial clair, à votre rythme : **Brouillon → À relire → Prêt → ✦ Publié**.</mark> Un voyant coloré sur chaque carte, un clic pour avancer d'une étape, et des filtres pour ne voir qu'une étape à la fois. Le tout dans la vue Notes — et seulement là.

## Deux moments, deux espaces

Keepsake distingue depuis toujours l'Inbox et la vue Notes. Le pipeline éditorial rend cette distinction encore plus nette, parce qu'elle correspond à deux moments différents de la journée.

L'**Inbox**, c'est le triage. On y vit la journée : on relit vite, on agit — archiver, supprimer, transformer en tâche — et on passe. On n'y écrit pas, on n'y réfléchit pas. C'est un lieu de débit, pas de réflexion. Pour cette raison, les notes de l'Inbox ne portent jamais de statut : un statut ralentirait précisément ce qui doit rester rapide.

La **vue Notes**, c'est l'atelier. On y prend le temps : on relit, on peaufine, et si une note mérite d'être publiée, elle entre dans le pipeline. Une note est déjà archivée quand elle entre dans le pipeline — rien ne bouge dans votre dos, aucun effet de bord.

Cette séparation n'est pas un détail d'interface. C'est le principe : ne pas demander à un même espace de servir deux intentions opposées. Le triage veut de la vitesse. L'écriture veut du calme.

## Quatre étapes, un voyant coloré

Une note dans le pipeline traverse jusqu'à quatre étapes :

- **Brouillon** — la note est commencée mais pas finie. Vous écrivez encore, vous rassemblez, vous façonnez.
- **À relire** — la note est écrite, il reste à la relire : vérifier la formulation, élaguer, contrôler.
- **Prêt** — la note est relue, prête à publier quand vous le déciderez. Elle attend le bon moment.
- **✦ Publié** — la note est en ligne sur votre Page Keepsake.

Chaque carte de note affiche une petite pastille colorée pour son étape. Vous lisez l'état de votre atelier d'un coup d'œil. Pour faire avancer une note, un clic sur le voyant suffit — pas de menu, pas de formulaire.

Détail important : **« Publié » n'est pas un statut que vous posez**. Il découle du fait que la note a réellement été publiée. Une note ne peut donc jamais se prétendre publiée tout en étant absente de votre page publique. L'état affiché correspond toujours à la réalité, pas à une intention.

## Optionnel par construction

Le pipeline est une manière de penser, pas une règle à suivre. Beaucoup de notes n'y entrent jamais — recettes, identifiants, matériel de référence — et c'est voulu. Une note sans statut n'est simplement pas dans le pipeline, et un filtre « Sans statut » permet de retrouver toutes ces notes-là.

Dans la vue Notes, une rangée de filtres laisse se concentrer sur une étape : **Tous · Sans statut · Brouillon · À relire · Prêt · Publié**. Filtrez par *Prêt* avant une session de publication pour voir tout ce qui est en file. Par *À relire* quand vous avez dix minutes pour peaufiner. Par *Sans statut* pour redécouvrir vos notes de référence. Une note peut aussi passer directement de « sans statut » à « publié » si c'est ainsi que vous travaillez.

La voie rapide reste intacte : publier une note depuis l'Inbox l'archive aussi, en un clic. Le pipeline multi-étapes, lui, reste l'apanage de l'atelier.

## Et la navigation se souvient d'où vous veniez

Cette mise à jour apporte aussi une amélioration discrète mais qui change le quotidien : <mark>quand vous revenez en arrière, Keepsake vous repose exactement là où vous étiez.</mark>

Vous parcouriez une longue liste de notes, vous ouvrez l'une d'elles, vous revenez : vous retrouvez l'endroit précis que vous consultiez, pas le haut de la page. Et le bouton retour vous reconduit vraiment à la vue d'origine, même après plusieurs détours. La position de défilement et le fil de navigation sont préservés — pour que naviguer dans Keepsake ne vous fasse jamais perdre votre place.

## À vous de jouer

Le pipeline éditorial est actif dès maintenant dans la vue Notes. Ouvrez une note que vous comptez publier un jour, cliquez sur son voyant, et faites-la cheminer à votre rythme.

Pour les détails — étapes, filtres, bonnes pratiques — l'article du centre d'aide [Le pipeline éditorial : du brouillon à la note publiée](https://keepsake.place/help/note-publishing-pipeline) couvre tout. Et pour voir où mène ce chemin, [la Page Keepsake de Nicolas](https://keepsake.place/@nicolas) montre des notes arrivées au bout du pipeline : publiées.

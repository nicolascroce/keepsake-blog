Capturer, organiser, publier : Keepsake vous aide à transformer une idée en publication, sur votre page publique. Mais une publication ne vit pas en vase clos — elle mérite de voyager. Cette mise à jour prolonge ce chemin, de votre note jusqu'à vos lecteurs, où qu'ils soient.

<mark>Reliez Typefully pour diffuser vos notes publiées sur vos réseaux, partagez des liens avec une vraie carte d'aperçu, et copiez le contenu d'une note dans le format qu'il vous faut.</mark>

## Publiez sur vos réseaux, depuis Keepsake

Vous écrivez dans Keepsake. Vous publiez sur votre page. Et ensuite ? Souvent, il faut tout recopier ailleurs pour le partager sur X ou Threads. Ce détour disparaît.

<mark>Reliez votre compte Typefully, et chaque note publiée peut partir sur vos réseaux d'un seul bouton.</mark>

La connexion se fait une fois, dans les réglages : vous ajoutez votre clé API Typefully, vous choisissez votre social set et les réseaux où diffuser — X, Threads, et les autres. Ensuite, chaque post publié porte une action de partage. Un clic, et il rejoint la file de Typefully, prêt à partir selon votre programmation. Besoin de le renvoyer ? C'est possible à tout moment.

Typefully reste votre tour de contrôle : programmation, fils, aperçus. Keepsake se contente de lui passer le relais — votre atelier d'écriture et votre outil de diffusion, enfin reliés.

## Partagez un lien, élégamment

Toutes les publications ne sont pas des textes. Parfois, ce que vous voulez partager, c'est une découverte : un article, un outil, une page qui mérite le détour.

<mark>Un nouveau type de publication arrive : le lien.</mark> Collez une adresse, et votre page publique ne se contente pas d'afficher une URL nue. Elle compose une carte soignée — l'image, le titre et la description du site — comme sur les meilleures plateformes. Vos lecteurs voient d'un coup d'œil où vous les emmenez, et pourquoi ça vaut le clic.

C'est une façon simple de faire de votre page publique un lieu de curation, pas seulement d'écriture.

## Copiez le contenu, dans le bon format

Vos mots vous appartiennent, et ils doivent pouvoir sortir de Keepsake aussi facilement qu'ils y sont entrés.

<mark>Un nouveau menu « Copier le contenu » apparaît sur vos notes</mark>, depuis la carte comme depuis l'éditeur. Récupérez le texte en un clic, dans le format qui vous arrange : texte simple pour le coller n'importe où, Markdown pour préserver la mise en forme. Prêt à partir vers un email, un document, un autre outil.

## À vous de jouer

Tout est actif dès maintenant. Reliez Typefully dans vos réglages, et regardez votre prochaine note publiée rejoindre vos réseaux d'un bouton. Collez un lien dans une note, et voyez la carte se composer toute seule.

Pour les détails, le centre d'aide vous accompagne : [Connecter Typefully pour publier sur vos réseaux](https://keepsake.place/help/connect-typefully).
